# Contributing to tmux-sidecar

Thanks for your interest in contributing! 🎉

## Development setup

```bash
# Install dependencies (requires uv)
uv sync
```

## Running tests

```bash
uv run pytest
```

## Submitting changes

1. Fork the repository and create a feature branch.
2. Make your changes with clear, focused commits.
3. Run the test suite before pushing.
4. Open a pull request describing what you changed and why.

## Style

- Keep changes small and focused — one logical change per PR.
- Follow the existing code style in the project.
- Update the README if you change user-facing behavior.

## Questions

Open a [Discussion](https://github.com/Logic-H/tmux-sidecar/discussions) for questions or ideas before writing code.
