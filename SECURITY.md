# Security Policy

## Reporting a Vulnerability

If you discover a security issue in tmux-sidecar, please **do not open a public issue**.

Report it privately by emailing the maintainer or opening a private advisory at:

https://github.com/Logic-H/tmux-sidecar/security/advisories/new

We aim to acknowledge reports within 48 hours and will coordinate disclosure once a fix is available.

## Scope

- The tmux-sidecar MCP server source code
- The bundled configuration examples

Out-of-scope: vulnerabilities in tmux itself or in the AI clients that connect to the server.
